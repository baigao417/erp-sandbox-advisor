# 通用经营核对方法

本页是自写方法摘要，不包含任何特定课程、赛事、团队或真实对局的规则和参数。所有阈值、权重、期限与费用应来自使用者获准使用的规则。

1. 先锁定口径：金额单位、期间编号、资格生效时点、库存费用的适用时点和重复罚款处理方式。无法确认的规则保留为待确认事项，不代填。
2. 先检查现金暴露：按时间列明采购、维护、投资、借还款和收款；季度总现金为正不能证明季度内不缺钱。
3. 逐单核对资格、原料、生产能力与交期。产能和库存必须跨订单去重，不能把独立可行当成组合可行。
4. 比较贡献而非仅比较销售额；显式计入分摊费用、融资成本和库存占用。贡献不是净利润。
5. 对库存计算期间超额费用与年度费用，并说明保留库存的收益是否覆盖成本。阈值不是普遍适用的行业规则。
6. 比较保守、均衡和扩张方案。每个方案列出假设、约束、现金缺口、交付风险、补救条件和人工决策点。

当前 CLI 只支持现金事件、独立订单、线性排名和库存快照计算。原料提前期、生产线冲突、贷款合法性、战略搜索及完整会计核算仍需人工或其他工具完成。
